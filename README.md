👑 ADMIN PANEL — "/admin"

Configure the following environment variables:

ADMIN_USER=your_admin_username
ADMIN_PASS=your_secure_password

If either variable is missing, "/admin" returns 404.

Admin Dashboard

1. Overview

- Total accounts.
- Users online now.
- 24-hour active users.
- 7-day active users.
- Live messages.
- 14-day activity chart.
- System health.

2. Lynko Official

- Post official announcements.
- Delete official messages.
- Verified Lynko Official chat.
- Visible to every account.
- Users cannot reply.

3. Errors

- Server errors.
- Browser errors.
- Process errors.
- Grouped error reporting.
- 14-day error retention.

4. Users

- Recent accounts.
- Searchable usernames.
- User IDs.
- Last seen information.
- No access to encrypted private chat contents.

Admin Security

- Lockout after 6 incorrect password attempts.
- 15-minute lockout per IP.
- Admin session lasts 12 hours.
- Changing "ADMIN_PASS" invalidates existing admin sessions.
